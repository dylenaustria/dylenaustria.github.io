After spending time working with our buzzers, we are tasked to make a code that allows us to use our buzzer and plays our favorite song or any song we find in the internet.

The goal of this code was to make a code that will play our favorite song. What I did here is that I searched up Arduino buzzers songs and then I came accross this website that has a list of songs. In this list, I chose the theme song from Fast and Furios: Tokyo Drift song. I then incorporated this code to my code and modified it so that when my swtich is off, the song stops and when my switch is on, the song starts to play again.


A tip/trick that I did here to make sure that my code worked is that I had to first make sure if my switch code worked. After seeing that is was working, I then incorporated it tot song code, but this process to me a while to do.
