Recently in class, we learned about If statements and here I made a code that lights one LED per second — Yellow for multiples of 5, Red for multiples of 6, Green for multiples of 7, or Blue for multiples of 8. 
I also included a code that prints count = # and what color it is on Serial Monitor.
I tip/trick that I used here is to make sure to section my code. By doing this tip, I can better understand my code and make my code look neat and clean. Also it can help to see where errors are located as well.
