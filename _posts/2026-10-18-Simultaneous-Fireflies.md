Recently in class, we learned about while loops and here we made a code will allow us to turn on random LEDs by a press of a button. We programmed it in a way that only one color of LEDs should be on at a time and the LED stays on when the button is still pressed. Then as we let go of the button, the LED turns off and then chooses another random pin to turn on.

A tip/trick that I used here is to make sure to section my code. By doing this tip, I can better understand my code and make my code look neat and clean. Also it can help to see where errors are located as well. Another tip that I used here is that I commented on each section so that I know how each section works.
